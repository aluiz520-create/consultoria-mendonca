# Produtos pagos — por que esta pasta está quase vazia

Este repositório é **público** (`aluiz520-create/consultoria-mendonca`, visibilidade
`public`). Qualquer pessoa consegue ler qualquer arquivo dele pelo GitHub, mesmo os que não
aparecem no site.

Ou seja: **conteúdo de produto pago não pode morar aqui.** Se morasse, o Guia de R$ 29
estaria disponível de graça para quem digitasse o caminho do arquivo — e bastaria um
comprador perceber isso para o produto perder o valor.

Por isso o `.gitignore` exclui `NEGOCIO/produto/*.md`.

## Onde está o master do Guia Anti-Rejeição

O arquivo `guia-anti-rejeicao.md` foi **entregue direto ao proprietário no chat**, fora do
Git. Ele é o master: é dele que sai o PDF vendido.

## O que fazer com ele

1. Abrir o `.md` (qualquer editor, ou colar no Google Docs / Word).
2. Exportar em PDF, mantendo a folha de conferência do capítulo 8 em uma página só —
   ela é feita para ser impressa e ficar do lado do monitor.
3. Subir o PDF como entrega do produto na Kiwify.
4. Guardar o `.md` em algum lugar seu (Drive, computador). Ele é a fonte para as próximas
   versões.

## Se um dia quiser versionar o produto

Duas saídas, nenhuma delas "colocar o arquivo de volta aqui":

- **Repositório privado separado** só para os masters dos produtos.
- **Tornar este repositório privado** — mas atenção: o GitHub Pages em repositório privado
  exige plano pago. Como o site depende do Pages, isso derruba o site no plano gratuito.

## Regra permanente

> Nada que alguém paga para receber entra neste repositório.
