## As regras que valem para tudo aqui

1. **Nenhum número sem fonte.** Onde não há dado, está escrito "não medido" — nunca zero
   presumido, nunca estimativa disfarçada de fato.
2. **Nenhuma venda inventada.** Valor de venda só entra no painel depois de confirmado no
   extrato da Kiwify ou no Pix.
3. **Nenhuma página só para encher o site.** Cada uma precisa passar no teste: *se eu fosse a
   pessoa que fez essa busca, isto resolveria meu problema?*
4. **Nenhuma técnica de spam.** Sem keyword stuffing, sem conteúdo copiado, sem centenas de
   páginas quase iguais, sem bot, sem seguidor comprado, sem link jogado em comentário.
5. **Nenhum afiliado de crédito.** É a monetização óbvia deste nicho e é lucrar com o problema
   que a ferramenta diz resolver.
