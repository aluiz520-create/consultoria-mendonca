# Plano de Monetização — Consultoria Mendonça → SaaS Agro

> Documento de estratégia de negócio, elaborado a partir do perfil real do fundador (parametrização fiscal SIAGRI, gestão administrativa/financeira/fiscal, análise de custos agrícolas) e dos ativos já existentes deste negócio: e-book de parametrização fiscal (R$ 147), planilha de controle de custos por fazenda (R$ 97), modelo de contrato de arrendamento (R$ 67), Kit CST/cClassTrib/cBenef do Agro-GO (R$ 197), blog de SEO sobre NFP-e/Reforma Tributária e canal de captação via WhatsApp.
>
> A tese central deste plano é simples: **você já validou a demanda**. Quatro produtos digitais estáticos já venderam. O próximo passo natural — e de maior alavancagem — não é inventar um mercado novo, é transformar esses produtos estáticos em um **SaaS recorrente**, vendido para a mesma base de clientes (produtores, escritórios contábeis do agro e cerealistas de Itaberaí/Goiânia/GO) que já confia na sua marca.

## 4. Top 10 oportunidades — detalhamento

### 1. Dashboard de Custo por Hectare Multi-Fazenda
- **Problema que resolve:** produtor e escritório contábil não sabem, em tempo real, o custo por hectare/saca de soja, milho e feijão por fazenda — só descobrem no fechamento da safra, tarde demais para corrigir rota.
- **Público-alvo:** produtores rurais com 2+ fazendas/talhões, escritórios de contabilidade rural, consultores agrícolas.
- **Modelo de cobrança:** assinatura mensal por fazenda/CNPJ cadastrado.
- **MVP em 7 dias:** planilha (Google Sheets) + formulário de lançamento de custo → dashboard web somente leitura (Next.js + Supabase) com 4 gráficos: custo/ha por categoria, custo/saca, comparação entre talhões, evolução mensal.
- **Tecnologias:** Next.js, Supabase (Postgres + Auth), Tailwind, Recharts.
- **Como vender:** oferecer upgrade grátis por 30 dias para quem já comprou a planilha de custos (R$ 97); depois WhatsApp direto para carteira de clientes de consultoria.
- **Estratégia de marketing:** blog (SEO já existente sobre agro/fiscal) + posts "quanto custa 1 saca de soja em 2026" + grupos de WhatsApp de produtores de Itaberaí/região.
- **Preço sugerido:** R$ 97/mês (1 fazenda) a R$ 297/mês (até 5 fazendas).

### 2. SaaS de Gestão de Contratos de Arrendamento e Parceria
- **Problema que resolve:** contratos de arrendamento/parceria ficam em PDF avulso, sem controle de vencimento, reajuste (sacas/ha) e histórico de aditivos — gera briga e prejuízo no acerto de safra.
- **Público-alvo:** produtores arrendatários/arrendadores, imobiliárias rurais, escritórios de advocacia agrária.
- **Modelo de cobrança:** assinatura mensal por número de contratos ativos + setup de migração dos contratos existentes.
- **MVP em 7 dias:** cadastro de contrato (partes, área, prazo, forma de pagamento em sacas), alerta automático de vencimento/reajuste, geração de PDF a partir do template já vendido.
- **Tecnologias:** Next.js, Supabase, geração de PDF (react-pdf), WhatsApp Cloud API para alertas.
- **Como vender:** todo comprador do modelo de contrato (R$ 67) vira lead quente; oferta "leve o contrato pronto + painel de vencimentos por 3 meses grátis".
- **Estratégia de marketing:** parceria com cartórios/imobiliárias rurais locais, indicação de clientes de consultoria fiscal.
- **Preço sugerido:** R$ 47/mês (até 3 contratos) a R$ 197/mês (ilimitado + alertas WhatsApp).

### 3. Painel Fiscal CST/cClassTrib/cBenef com Atualização Automática
- **Problema que resolve:** as tabelas de cBenef de Goiás e o cClassTrib da Reforma Tributária mudam com frequência em 2026 — o Kit estático (R$ 197) fica desatualizado em meses.
- **Público-alvo:** escritórios contábeis do agro, produtores que emitem NF-e/NFP-e direto, revendas de insumos.
- **Modelo de cobrança:** assinatura anual ou mensal para acesso ao painel sempre atualizado + busca por NCM/produto.
- **MVP em 7 dias:** banco de dados com as tabelas já compiladas no Kit + página de busca (NCM → CST/cClassTrib/cBenef) + changelog de atualizações.
- **Tecnologias:** Next.js, Supabase, cron job mensal de checagem manual/semi-automática das tabelas SEFAZ-GO.
- **Como vender:** upsell direto para os compradores do Kit ("de estático para sempre atualizado"); parceria com escritórios contábeis (revenda com desconto por volume).
- **Estratégia de marketing:** os 3 artigos de blog já publicados (cBenef, Reforma Tributária, IBS/CBS) já rankeiam para esse público — colocar CTA de assinatura neles.
- **Preço sugerido:** R$ 39/mês por usuário ou R$ 390/ano.

### 4. Assistente de IA via WhatsApp para Dúvidas de Parametrização SIAGRI
- **Problema que resolve:** dúvidas do dia a dia de parametrização (qual CST usar, por que a nota foi rejeitada) hoje só se resolvem chamando você direto — não escala.
- **Público-alvo:** operadores de escritórios contábeis e produtores que usam SIAGRI/myFarm.
- **Modelo de cobrança:** assinatura mensal por número de WhatsApp autorizado a consultar o bot.
- **MVP em 7 dias:** número de WhatsApp Business + Claude API com prompt especializado em SIAGRI/fiscal agro (base de conhecimento = seu e-book + Kit) respondendo perguntas simples; escalonamento manual para você quando o bot não sabe.
- **Tecnologias:** WhatsApp Cloud API (Meta) ou Z-API, Claude API (Sonnet), Supabase para histórico e limite de uso.
- **Como vender:** trial de 7 dias grátis para clientes atuais de consultoria; "seu segundo consultor, disponível 24h, por uma fração do preço".
- **Estratégia de marketing:** vídeo curto mostrando o bot respondendo uma dúvida real de parametrização, compartilhado em grupos de WhatsApp/Facebook de contadores do agro.
- **Preço sugerido:** R$ 147/mês por número autorizado.

### 5. Sistema de Controle de Armazenagem e Expedição
- **Problema que resolve:** armazéns e cerealistas pequenos/médios controlam entrada, saída, umidade e classificação de grãos em planilha ou papel, sem rastreabilidade por lote/depositante.
- **Público-alvo:** armazéns gerais, cerealistas, cooperativas pequenas sem ERP robusto (ou que usam SIAGRI mas querem um controle operacional de pátio/balança mais ágil).
- **Modelo de cobrança:** assinatura mensal por unidade armazenadora + módulo de balança.
- **MVP em 7 dias:** cadastro de depositante/lote, lançamento manual de pesagem (entrada/saída), relatório de saldo por depositante.
- **Tecnologias:** Next.js, Supabase, leitura de planilha/CSV da balança como ponte inicial (antes de integração direta).
- **Como vender:** visita/demonstração presencial em armazéns da região (Itaberaí/Goiânia), aproveitando sua rede de contatos SIAGRI.
- **Estratégia de marketing:** case de sucesso documentado + indicação boca a boca (mercado de armazéns é pequeno e conectado).
- **Preço sugerido:** R$ 397–997/mês por unidade, conforme volume.

### 6. Ferramenta de Conciliação de Estoque de Grãos
- **Problema que resolve:** divergência entre estoque físico, estoque contábil (SIAGRI) e romaneios de balança é dor de cabeça recorrente em fechamento de safra/auditoria.
- **Público-alvo:** cerealistas, armazéns, cooperativas.
- **Modelo de cobrança:** assinatura mensal ou serviço avulso de conciliação + auditoria mensal recorrente.
- **MVP em 7 dias:** upload de 2 planilhas (saída do SIAGRI + romaneios) → relatório automático de divergências por lote/depositante.
- **Tecnologias:** Next.js, processamento de planilha (SheetJS), Supabase.
- **Como vender:** oferecer 1 conciliação grátis como prova de valor para clientes de armazenagem/SIAGRI.
- **Estratégia de marketing:** conteúdo técnico "5 erros mais comuns na conciliação de estoque de grãos" no blog.
- **Preço sugerido:** R$ 297/mês (mensalidade) ou R$ 450 por conciliação avulsa.

### 7. Robô de Alertas Fiscais via WhatsApp
- **Problema que resolve:** prazos de obrigações fiscais e mudanças de cBenef/CST pegam produtores e contadores de surpresa.
- **Público-alvo:** produtores rurais, escritórios contábeis do agro.
- **Modelo de cobrança:** assinatura mensal simples, baixo ticket, alto volume.
- **MVP em 7 dias:** lista de transmissão/grupo de WhatsApp + rotina manual (depois automatizada) de envio de alertas de prazos e mudanças relevantes.
- **Tecnologias:** WhatsApp Business API, planilha/Supabase como calendário fiscal, automação simples (n8n ou script agendado).
- **Como vender:** oferta gratuita por 30 dias para captar lista (usa o checklist grátis da NFP-e já existente como isca) e depois converter para pago.
- **Estratégia de marketing:** o próprio lead magnet "checklist grátis da NFP-e" já existente no site vira porta de entrada para essa lista.
- **Preço sugerido:** R$ 27–47/mês por número.

### 8. SaaS de Controle de Financiamentos Rurais
- **Problema que resolve:** produtores com múltiplas linhas de crédito (Pronaf, Pronamp, custeio, investimento) perdem o controle de parcelas, carência e vencimento entre bancos diferentes.
- **Público-alvo:** produtores rurais com financiamento ativo, escritórios de gestão rural.
- **Modelo de cobrança:** assinatura mensal por CPF/CNPJ.
- **MVP em 7 dias:** cadastro manual de contratos de crédito (banco, valor, taxa, parcelas, carência) + dashboard de fluxo de caixa de parcelas futuras + alerta de vencimento.
- **Tecnologias:** Next.js, Supabase, WhatsApp para alertas.
- **Como vender:** incluir como módulo adicional do dashboard financeiro (item 1), venda cruzada.
- **Estratégia de marketing:** conteúdo sobre "como organizar múltiplos financiamentos rurais sem perder prazo".
- **Preço sugerido:** R$ 67/mês (incluso no plano financeiro maior).

### 9. Dashboard de Break-even e Simulação de Preço de Venda por Fazenda
- **Problema que resolve:** produtor não sabe, na hora de vender no mercado físico ou travar preço futuro, qual é o seu ponto de equilíbrio real por fazenda/talhão.
- **Público-alvo:** produtores de soja/milho/feijão, consultores de comercialização agrícola.
- **Modelo de cobrança:** assinatura mensal, cobrando junto com o dashboard de custos (mesma base de dados).
- **MVP em 7 dias:** a partir dos dados de custo por hectare já lançados, calcular break-even em R$/saca e simular cenários de preço.
- **Tecnologias:** Next.js, Supabase (reaproveita schema do item 1).
- **Como vender:** módulo adicional dentro do mesmo produto do item 1 — não é um produto separado a vender, é um upsell natural.
- **Estratégia de marketing:** conteúdo "quanto você precisa vender a saca para não ter prejuízo em 2026".
- **Preço sugerido:** incluso no plano Pro (R$ 297/mês) do dashboard de custos.

### 10. Plataforma de Indicadores para Cooperativas e Cerealistas
- **Problema que resolve:** cooperativas e cerealistas médios não têm visão consolidada (BI) de recebimento, armazenagem e posição de estoque em um só painel.
- **Público-alvo:** cooperativas regionais, cerealistas de médio porte.
- **Modelo de cobrança:** contrato mensal + setup de integração de dados (ticket mais alto, ciclo de venda mais longo).
- **MVP em 7 dias:** protótipo de dashboard com dados de exemplo/planilha exportada do SIAGRI, para validar com 1 cliente-piloto antes de construir integração real.
- **Tecnologias:** Next.js, Supabase ou conexão direta a banco de dados do cliente, biblioteca de gráficos.
- **Como vender:** venda consultiva direta (reunião presencial/vídeo), não é self-service.
- **Estratégia de marketing:** indicação via rede de contatos SIAGRI + estudo de caso com o primeiro cliente piloto.
- **Preço sugerido:** R$ 997–2.500/mês por unidade, conforme porte.

## 5. Oportunidade escolhida e plano de execução de 90 dias

### Por que o Dashboard de Custo por Hectare Multi-Fazenda (produto "SafraCerta")

Entre as 20 opções, esta é a que melhor combina, para o **seu** perfil específico e para uma rotina de **2h/dia**:

- Você já vende a versão estática (planilha, R$ 97) — existe lista de compradores para fazer upsell imediato, custo de aquisição de cliente próximo de zero.
- É a opção com maior nota de facilidade (8/10) e menor tempo até faturar (2–3 semanas) entre as de alta escalabilidade.
- Cabe dentro do seu domínio técnico atual (Excel avançado, dashboards, fórmulas) — o salto para Next.js/Supabase é gerenciável em poucas semanas de estudo direcionado.
- Os módulos de contrato (item 2), alertas fiscais (item 7) e financiamentos (item 8) entram depois como **upsell dentro do mesmo produto**, sem precisar vender um SaaS novo — você constrói uma plataforma, não cinco produtos isolados.

**Nome do produto:** SafraCerta — Painel de Custo, Contrato e Fiscal para o Agro (nome provisório, ajustável).

### O que aprender (nessa ordem)
1. **HTML/CSS/JS básico** (se ainda não domina) — 1 semana, cursos gratuitos (freeCodeCamp, Rocketseat Discover).
2. **React + Next.js** (App Router) — o suficiente para criar formulários, listas e páginas protegidas por login.
3. **Supabase**: tabelas, autenticação, Row Level Security (RLS) — fundamental para isolar dados de cada fazenda/cliente.
4. **Tailwind CSS** — estilização rápida sem escrever CSS do zero.
5. **Integração de pagamento recorrente no Brasil** (Asaas ou Stripe) — assinaturas, webhooks de confirmação.
6. **WhatsApp Cloud API ou Z-API** — envio de mensagens automáticas (alertas).
7. **Uso da API da Claude/OpenAI** para gerar insights automáticos em linguagem natural a partir dos dados do dashboard (diferencial competitivo).

### Código que deve ser desenvolvido
- Autenticação (login/cadastro) com isolamento de dados por conta (multi-tenant).
- CRUD de fazendas, safras e talhões.
- CRUD de categorias e lançamentos de custo.
- Cálculo de agregações (custo/ha, custo/saca) — via função no banco (Postgres) ou API route.
- Dashboard com gráficos (Recharts ou similar).
- Módulo de break-even/simulação de preço.
- Módulo de contratos (cadastro, geração de PDF, alertas de vencimento).
- Integração de cobrança recorrente (planos, webhook de pagamento confirmado/cancelado).
- Bot de alertas via WhatsApp (vencimentos e lembretes de lançamento mensal).
- Painel administrativo simples para você acompanhar clientes ativos/inadimplentes.

*(Ver `docs/arquitetura-tecnica-saas.md` para a estrutura técnica detalhada.)*

### Estrutura do projeto
Ver seção "Estrutura de pastas" em `docs/arquitetura-tecnica-saas.md`.

### Banco de dados recomendado
**Supabase (Postgres gerenciado)** — motivos: autenticação pronta, Row Level Security nativo (essencial para multi-tenant sem vazar dados entre clientes), plano gratuito generoso para os primeiros meses, boa documentação em português na comunidade, e permite consultas SQL diretas quando o volume de dados crescer (relatórios para cooperativas/cerealistas no futuro).

### APIs necessárias
- **Supabase** (banco de dados + autenticação).
- **Vercel** (hospedagem do Next.js).
- **Asaas** ou **Stripe** (cobrança recorrente via Pix/boleto/cartão — Asaas é mais amigável ao mercado brasileiro de pequenos assinantes).
- **WhatsApp Cloud API (Meta)** ou **Z-API** (alertas automáticos).
- **Claude API (Anthropic)** (insights automáticos em linguagem natural, futuro assistente do item 4).
- **Resend** ou similar (e-mails transacionais: boas-vindas, cobrança, recuperação de senha).

- **6 meses:** 30–35 clientes (mix Starter R$ 97 / Pro R$ 297), **MRR ≈ R$ 10.000/mês** — bate a meta.
